## Français

**ZOcre Framework** est désormais présenté et distribué via son organisation GitHub officielle.

- **[Organisation officielle ZOcre Framework](https://github.com/zocre-framework-official)** — point d'entrée principal.
- **[ZOcre Control](https://github.com/zocre-framework-official/zocre-control)** — application Windows de déploiement et de gestion des serveurs NANOS / nanos world.
- **[ZOcre Loading Screen](https://github.com/zocre-framework-official/zocre-loading-screen)** — page et package public du loading screen ZOcre.
- **[Support et documentation publique](https://github.com/zocre-framework-official/.github/blob/main/SUPPORT.md)** — assistance et informations officielles.
- **[Discord officiel](https://discord.gg/Ey4dn4Cbqj)** — communauté et annonces.

### Compatibilité des anciennes installations

Certains logiciels distribués précédemment peuvent encore rechercher des fichiers de mise à jour sous cette adresse. Les manifestes, chemins de compatibilité, fichiers de licence et noms d'artefacts historiques ne doivent pas être renommés ou supprimés sans validation technique.

Pour les **nouvelles installations**, consultez exclusivement les dépôts et releases publiés par l'organisation officielle. La disponibilité des versions est précisée sur les pages produit respectives.

## English

**ZOcre Framework has moved to its official GitHub organization: [zocre-framework-official](https://github.com/zocre-framework-official).**

This personal repository is a **historical compatibility endpoint only**, not the publication location for new ZOcre products, packages or releases.

- **[Official organization](https://github.com/zocre-framework-official)**
- **[ZOcre Control](https://github.com/zocre-framework-official/zocre-control)**
- **[ZOcre Loading Screen](https://github.com/zocre-framework-official/zocre-loading-screen)**
- **[Public support](https://github.com/zocre-framework-official/.github/blob/main/SUPPORT.md)**
- **[Official Discord](https://discord.gg/Ey4dn4Cbqj)**

Some previously distributed installations may still rely on historic update paths. Technical compatibility files, release filenames and historical license documents are therefore retained unchanged until the migration has been verified.

For **new installations**, use only the official organization's repositories and approved releases.
